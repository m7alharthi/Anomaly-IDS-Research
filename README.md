# Anomaly-Based Intrusion Detection System using Log Correlation and Machine Learning

## Research Project

This project focuses on developing an anomaly-based intrusion detection system using log correlation and machine learning techniques.

## Objectives

- Collect security logs from different sources
- Normalize and preprocess log data
- Apply log correlation techniques
- Detect anomalous behavior using machine learning models
- Reduce false positive alerts
- Improve real-time intrusion detection capabilities

## Technologies

- Python
- Machine Learning
- Elasticsearch
- Logstash
- Kibana
- Suricata IDS
- Security Onion
- Wazuh

## Research Area

Cybersecurity | Intrusion Detection Systems | Anomaly Detection | Machine Learning
